# 서울시립과학관 기준 크기 조정

사용자가 지정한 [서울시립과학관 메인](https://science.seoul.go.kr/main)을 Chrome에서 390·768·1024·1280·1440·1920px로 열어 실제 치수를 비교했다. 기존 상상마루의 콘텐츠·사진·축구장 디자인·라우팅은 유지한다.

## 적용 기준

| 항목 | 시립과학관 실측 | 상상마루 적용 |
| --- | --- | --- |
| PC 1차 메뉴 | 20px | 20px |
| PC 기관 메뉴 줄 | 약 90px, 테두리 포함 약 91px | 90px, 테두리 포함 91px |
| PC 로고 | 약 160px 너비 | 160px |
| 공통 외곽 최대 폭 | 1550px | 1550px |
| 공통 안쪽 좌우 여백 | 15px | 15px |
| PC 기본 글자 배율 | 16px | 기본 16px, 큰 모니터의 추가 확대 제거 |
| 1920px 대표사진 | 약 984×577px | 약 985×579px |
| 1440px 대표사진 | 약 875×516px | 약 875×515px |
| 1920px 카드 폭 | 약 362px | 직업세계 362px, 프로그램 약 358px |
| 1440px 카드 폭 | 약 320px | 직업세계 320px, 프로그램 약 314px |
| 모바일 카드 폭 | 390px 화면에서 약 345px | 직업세계·프로그램 345px |

기관 메뉴 줄을 비교했으며 서울시 공통 상단 바 48px는 추가하지 않는다. 카드 높이는 각 프로그램의 기존 설명·태그 등 실제 내용에 따라 달라진다. 모바일은 원본 사이트의 12~13px 기본 글자 축소를 그대로 따라가지 않고, 기존 가독성을 위해 기본 16px을 유지한다.

## 반응형 동작

- 1280px부터 PC 메뉴를 표시한다. 그보다 작은 화면은 서랍 메뉴를 사용하고, PC 크기로 전환하면 서랍과 스크롤 잠금을 해제한다.
- 대표사진은 약 1.7:1 비율을 사용한다. 1300px 이하에서는 사진 아래에 소개·안내 패널을 배치하고, 800px 미만에서는 패널도 세로로 배치한다.
- 직업세계의 6개 카드 및 프로그램의 9개 항목은 유지한다. PC 프로그램 4열, 태블릿 2~3열, 모바일 1장을 기본으로 한다.
- 축구장 외곽·골대 여백과 기존 글자 위계, 2초 간격 메인 연혁 자동 전환은 유지한다.

## 검증

- 6개 화면 너비에서 가로 넘침·헤더 겹침 없음.
- PC 메뉴 20px·헤더 91px·최대 폭 1550px을 실제 계산값으로 확인.
- 1920px 및 1440px에서 대표사진과 오른쪽 안내 패널의 하단 정렬 확인.
- 직업세계 카드 폭 320~362px, 모바일 프로그램 카드 폭 345px 확인.
- 1024px 서랍 메뉴에서 1280px PC 메뉴로 전환할 때 스크롤 복원 확인.
- Hero 수동 탐색 및 2초 간격 연혁 전환 확인, 브라우저 런타임 오류 없음.
- 세부 결과·참고 사이트 측정값·캡처는 Git 제외 경로 `.data/reference-scale-validation.json`, `.data/reference-sizes.json`, `.data/uiux-reference-scale-*.png`에 보관.

주요 수정 위치: `src/app/globals.css`, `src/styles/typography.css`, `Header.tsx`, `MainNav.tsx`, `MobileMenu.tsx`, `Hero.css`, `CareerSection.css`, `ProgramSlider.tsx`.
