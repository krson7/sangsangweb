# Footer 간소화 및 정보 재배치

## 구현 범위

- `src/components/layout/Footer.tsx`: 바로가기와 인증·지정 영역을 제거하고, 기관 정보 오른쪽에 회사명·대표자 및 등록번호를 배치했다. 하단에 중복되던 사업자 목록도 제거했다.
- `src/components/layout/Footer.css`: 기관·사업자 정보의 두 영역으로 구성하고 불필요한 메뉴·인증 스타일을 제거했다. Footer 안팎의 세로 여백도 줄였다.

기존 `site-content-frame`의 공통 좌우 경계, 네이비 배경 `#172F4E`, 125×40px 로고, Pretendard를 유지한다. Header·Hero·다른 본문 컴포넌트와 설정 데이터는 수정하지 않았다.

## 정보 구성

- 1024px 이상은 왼쪽 기관 정보, 오른쪽 사업자 정보의 두 컬럼을 사용한다. 그보다 좁은 화면에서는 한 컬럼으로 전환한다.
- 로고 옆에 ‘호기심 충전소’와 기존 소개 문구를 배치한다. 아래에 주소와 전화·팩스·이메일을 정렬하며, 연락처는 내용 너비에 따라 줄바꿈한다.
- 인증·지정 정보는 Footer에서만 제거했다. 다른 섹션의 인증 데이터는 수정하지 않았다.
- 오른쪽 첫 줄에 법인명·대표자를 강조하고, 등록번호 3개는 아래에서 가로로 나열한다. 좁은 화면에서는 자연스럽게 줄바꿈한다.
- 하단 구분선 아래에는 저작권·관리자 링크·맨 위로 이동 버튼만 배치한다. 주소·연락처와 모든 사업자 정보는 기존 값을 유지했다.
- 제목 16px·600, 연락처 14px·500, 등록번호와 일반 정보 13~14px로 계층을 구분한다.

- Chrome Headless에서 표의 모든 너비와 추가 320px·600px를 확인했다. 가로 넘침과 텍스트 잘림이 없다.
- 헤더·Hero·Footer의 좌우 끝선과 Footer 로고 시작점이 일치한다.
- 기존 기관·사업자 정보 11개 문자열이 모두 유지되고 등록번호 3개가 각각 한 번만 표시되는 것을 확인했다.
- 1280px 이상에서는 등록번호 3개가 같은 행에 놓이고, 좁은 화면에서는 잘리지 않고 줄바꿈한다.
- 바로가기와 인증·지정이 제거되고 전화·이메일·관리자 링크만 남은 것을 확인했다. 관리자 nofollow와 맨 위로 이동 기능도 정상이다.
- 브라우저 런타임 오류 없음. TypeScript·Lint·Build 통과, 빌드는 68개 페이지를 생성했다.
