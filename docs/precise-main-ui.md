# 헤더·메인 Hero 비율 조정

사용자가 제시한 1784×864px 화면의 추정 치수와 [서울시립과학관 실제 메인](https://science.seoul.go.kr/main)을 기준으로 조정했다. 실제 사이트를 같은 뷰포트와 배율로 캡처해 비교했다. 상상마루의 로고·메뉴·교육 사진·연락처·주소·링크를 사용한다.

## 적용 파일

- `src/components/layout/Header.tsx`, `Header.css`: 기관명·브랜드 메시지와 유효한 링크로 구성한 Utility, 2단 헤더의 높이·로고·문의 버튼·공통 정렬 기준. 전체 헤더 높이 변수는 앵커 이동과 하위 메뉴의 고정 위치에도 반영한다.
- `src/components/layout/MainNav.tsx`: 균일한 메뉴 셀 너비.
- `src/components/home/Hero.tsx`, `Hero.css`: 좌우 비율, 카드 높이, 그라데이션, 둥근 모서리와 컨트롤, 이미지 sizes.
- `src/app/globals.css`: 헤더 높이 정의를 헤더 소유 스타일로 이동하고, 공통 스크롤 위치는 전체 헤더 높이를 사용한다.

기존 연혁·직업세계·프로그램·공지사항의 너비는 조정하지 않았다. 헤더 규격 작업에서는 헤더 높이·메뉴 글자·카드 비율·여백·컨트롤 크기를 보정했고, 아래 후속 작업에서 상단 카드에 캐릭터를 추가했다.

## 반응형 및 동작

- 1200px 이상에서는 이미지와 우측 두 카드를 나란히 배치한다. 이미지 높이는 520~545px 범위에서 조정하고 사진은 `object-fit: cover`로 크롭한다. 1280px에서도 카드가 이미지 아래로 밀리지 않는다. 해당 화면에서 이미지는 약 787×520px, 카드는 약 375px 너비로 줄어든다.
- 1199px 이하에서는 이미지 아래에 두 안내 카드를 나란히 배치한다.
- 799px 이하에서는 이미지·소개·교육 안내를 한 열로 배치한다.
- 모바일 헤더는 상단 32px·주 메뉴 64px로 구성한다. 작은 화면의 Utility에는 기관명과 교육문의 링크를 남긴다.
- 자동재생 간격 6.5초, 마우스 진입·키보드 포커스·화면 이탈·비활성 탭의 재생 중단 동작을 유지한다.
- reduced-motion 환경에서는 자동재생과 전환 애니메이션을 기본으로 중단하고, 사용자가 재생 버튼을 누르면 자동재생을 명시적으로 시작할 수 있다.

## 검증

- Chrome: 390·768·1024·1280·1440·1784·1920px에서 가로 넘침, 헤더와 Hero의 좌우 정렬, 글자 잘림, 카드 하단 정렬 확인. DPR 1·화면 배율 1을 공통으로 적용했다.
- 이번 비교 기준은 두 사이트 모두 1784×864px, DPR 1, 화면 배율 1이다. 참고 사이트의 실제 최대 폭은 1550px(내부 콘텐츠 1520px), 로고 약 160px, 메뉴 20px, 주 메뉴 높이 91px이다. 상상마루는 요청에 명시된 컨테이너 1430px·로고 150px·메뉴 17px·주 메뉴 85px를 우선 적용했다. 따라서 실제 사이트와의 완전한 픽셀 일치를 주장하지 않는다.
- 참고 사이트의 메인 이미지 실측은 984×577px, 카드 너비 약 477px, 콘텐츠 시작 Y좌표는 199px이다. 상상마루는 요청에 명시된 이미지 925×545px·카드 445px를 적용했으며 시작 Y좌표는 194px이다.
- 슬라이드 번호 표시부 183×92px, 재생·정지 버튼 35px, 이전·다음 버튼 64px, 번호 표시부와 화살표 사이 간격 27px, 이미지 아래 컨트롤 겹침 위치는 실제 참고 사이트의 측정값에 맞췄다.
- 슬라이드 이전·다음·정지·명시적 재생·기본 자동재생 및 reduced-motion 초기 정지를 다시 확인했다.
- 데스크톱 메뉴 열림·닫힘·하위 메뉴의 헤더 아래 배치, 모바일 메뉴 열림·Escape 닫기·스크롤 잠금 해제, 연혁 앵커가 2단 헤더 아래에 노출되는 것을 확인했다.
- 브라우저 런타임 오류 없음.
- `npm run lint` 통과.
- `npm run typecheck` 통과.
- `npm run build` 통과: TypeScript 검사와 68개 페이지 생성 완료.
- 로컬 측정값과 화면 캡처는 Git 제외 경로 `.data/layout-spec-validation.json`, `.data/uiux-spec-*.png`, `.data/reference-spec-1784.png`에 보관.
- 두 사이트의 1784px 캡처와 측정값을 나란히 볼 수 있는 단일 HTML 파일은 `.data/layout-comparison-1784.html`이다. 캡처 이미지를 파일 안에 포함해 네트워크 없이 열 수 있다.

## Hero 상단 캐릭터 카드 후속 개선

- 기존 public 에셋은 로봇·드론 교육 현장 사진으로 확인했다. 카드용 캐릭터는 `HeroEducationCharacters.tsx`에 별도 SVG 컴포넌트로 구현했다. 그라데이션과 하이라이트로 입체감을 표현하고, `useId`로 재사용 시 색상 정의 ID의 충돌을 방지한다.
- 상단 카드 내부는 문구 60%·캐릭터 40%로 나눴다. 기존 문구와 소개 링크는 유지하고 오른쪽에 소형 4축 드론, 인사하는 흰색·파란색 로봇을 배치한다. 장식 SVG는 접근성 트리에서 제외하며 링크 클릭을 가로채지 않는다.
- 데스크톱의 상단 카드 445×240px, 하단 카드 445×260px와 Hero 배치는 그대로다. 작은 화면의 자동 높이도 기존 높이에 맞춘 최소 높이로 유지한다.
- Hero 위치안내만 `site.address.locality`와 `site.address.street`를 사용해 ‘익산시 동서로49길 24-1, 2층’으로 표시한다. 공통 주소 데이터와 다른 페이지의 정식 주소는 변경하지 않았다.
- 390·768·1024·1280·1440·1784·1920px에서 제목·설명의 두 줄 유지, 문구와 캐릭터의 겹침 없음, 한 줄 주소와 가로 넘침 없음을 확인했다. 기존 화면 측정값과 비교했으며 데스크톱 치수는 동일하고, 태블릿·모바일의 높이 차이는 2px 미만이다.
- `npm run typecheck`, `npm run lint`, `npm run build` 통과. 브라우저 런타임 오류 없음.
- 검증: `.data/hero-characters-validation.json`. 전체 화면: `.data/uiux-hero-characters-*.png`. 카드 확대 캡처: `.data/hero-character-card-1784.png`, `.data/hero-character-card-390.png`.
