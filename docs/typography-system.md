# 상상마루 타이포그래피 시스템

기존 레이아웃·색상·사진·콘텐츠와 최근 조정한 글자 크기를 기준으로, 제목과 본문의 굵기·자간·행간을 정리했다. 공개 홈페이지에만 적용하며 관리자 화면은 기존 서식을 유지한다.

## 서체와 굵기

- 일반 UI와 본문: 자체 호스팅된 **Pretendard Variable**. 기존 서체 파일과 `font-display: swap`을 재사용한다.
- 일반 본문 400, 목록·강조 문장 500, 메뉴·레이블 600, 제목 700, 대표 문구·주요 숫자 750을 기본으로 한다.
- 축구장 프로그램 영역은 기존 **Paperlogy** 제목을 유지한다. 설치된 실제 굵기인 400·500·800을 사용하며 카드 제목은 500, 섹션 제목은 800이다. 긴 카드 본문은 Pretendard로 통일한다.
- 새로운 외부 폰트나 라이브러리를 추가하지 않는다.

## 크기와 위계

크기는 `rem` 기준이며, 1rem=16px 환경에서의 참고값이다. 시립과학관 크기 비교 작업 이후에는 큰 화면의 추가 배율을 제거하고 기본 16px을 유지한다. 상세 치수는 `reference-sizing.md`를 참고한다.

| 역할 | 토큰 | 기본 크기 | 행간·굵기 |
| --- | --- | --- | --- |
| 서브페이지 제목 | `--type-page-title` | 32~42px | 1.35 / 750 |
| 메인 섹션 제목 | `--type-section-title` | 30~38px | 1.35 / 700 |
| 공지·갤러리 제목 | `--type-panel-title` | 26~32px | 1.35 / 700 |
| 서브페이지 소제목 | `--type-subsection-title` | 24px, 모바일 22px | 1.35 / 700 |
| 교육 카드 제목 | `--type-card-title` | 22px | 1.5 / 700 |
| 사진 제목 | `--type-gallery-title` | 18~20px | 1.55 / 500 |
| 게시글 목록 제목 | `--type-list-title` | 17~18px | 1.5~1.6 / 500~600 |
| 소개·게시글 본문 | `--type-reading-body` | 17px | 1.8~1.85 / 400 |
| 카드 본문 | `--type-body` | 16px | 1.8, 모바일 1.75 / 400 |
| 보조 정보 | `--type-small` | 15px | 1.6 |
| 날짜·태그·캡션 | `--type-caption` | 13px | 1.6 |

PC 메뉴는 시립과학관의 실제 메뉴와 같은 20px을 사용하며, 작은 화면의 서랍 메뉴는 17px을 사용한다.

날짜가 중요한 공지·갤러리에서는 기존에 키운 14~15px 크기를 유지한다. Hero의 작은 배너 제목과 숫자 통계는 해당 영역의 크기 비율을 유지하고 공통 굵기·자간만 따른다.

## 자간·줄바꿈·여백

- 제목 자간은 -0.025em, 본문은 -0.01em, 메뉴·레이블은 -0.0125em을 기준으로 한다. 기존의 과도하게 좁은 제목 자간을 완화했다.
- 날짜와 표 형식 숫자는 동일한 숫자 폭을 사용하고 자간을 추가로 좁히지 않는다.
- 긴 한국어 본문은 기존 `word-break: keep-all`을 유지하고 자연스러운 줄바꿈을 사용한다. 제목의 균형 잡힌 줄바꿈 설정이 기존 말줄임의 `nowrap`을 해제하지 않도록 `text-wrap-style`만 지정한다.
- 소개 본문 문단 간격은 1rem으로 정리하고, 큰 제목·본문·보조 정보 사이의 위계가 보이도록 행간을 역할별로 분리한다.
- 게시글 본문·교육 상세·연혁 페이지의 소제목과 일반 글도 같은 기준을 사용한다.
- 고정된 이미지 비율, 카드 열 수, 축구장 배경, Hero의 사진·안내 배치, 연혁 자동 전환 동작은 유지한다.

## 적용 위치

- 기준 토큰·역할별 클래스: `src/styles/typography.css`
- 공개 레이아웃: `src/app/(site)/layout.tsx`
- 공통 제목 유틸리티: `src/app/globals.css`의 `t-h1`, `t-h2`, `t-h3`, `t-lead`
- Hero, 소개·통계, 직업세계, 공지·갤러리, 연혁: 각 컴포넌트의 기존 CSS에서 토큰 참조
- 프로그램: `Programs.tsx`의 Paperlogy 변수와 `ProgramSlider.tsx`의 제목·본문 역할 클래스
- 헤더·모바일 메뉴·푸터·서브페이지·커뮤니티 목록: `type-nav`, `type-menu-link`, `type-small`, `type-list-title` 등 공통 클래스

제목이나 본문의 새 크기가 필요할 때 컴포넌트마다 임의 크기를 늘리지 않고 해당 역할 토큰부터 검토한다. 기존 의미 기반 색상 유틸리티와 충돌하지 않도록 글자 역할은 `type-*` 클래스로 구분한다.

## 검증 기록

- lint, TypeScript, production build 통과. 기존 68개 정적 페이지 생성 확인.
- 연혁 정렬·원본 보존 회귀 검사 2건 통과.
- Chrome에서 메인 화면을 390 / 768 / 1024 / 1280 / 1440 / 1920px로 확인: 가로 넘침·헤더 겹침 없음, 직업세계 1·2·3열과 9개 프로그램 유지.
- 인사말·연혁·진로체험·프로그램 상세·공지 목록·사진 목록·게시글 상세를 390 / 1024 / 1440px에서 확인: 제목과 본문 역할 적용, 가로 넘침 없음.
- 실제 계산된 서체와 굵기 확인: 직업세계 제목 700·본문 400, Hero 제목 750, 프로그램 제목 Paperlogy 500·본문 Pretendard 400.
- 기존 말줄임이 한 줄로 유지되고 날짜에 추가 자간이 적용되지 않는지 확인.
- 연혁 2012→2013 자동 전환, Hero 수동 이동, 모바일 메뉴 포커스·Escape 닫기 확인. 관리자 로그인 화면에 공개 타이포그래피가 적용되지 않음을 확인.
- 브라우저 런타임 오류 없음. 상세 결과와 캡처는 Git 제외 경로 `.data/typography-validation.json`, `.data/uiux-type-*.png`에 보관.
