# 기관 소개 섹션 블랙&화이트 개선

## 작업 범위

`src/components/home/AboutIntro.tsx`와 `AboutIntro.css`만 수정했다. 공통 스타일, 다른 섹션, 데이터와 라우팅·API는 수정하지 않았다. 대화에 참고 이미지 파일이 표시되지 않아 사용자가 제시한 색상·글자 크기·배치 규격을 기준으로 구현했다.

## 디자인

- 공통 `container-site` 최대 너비와 기존 좌측 사진·우측 소개의 2단 구성을 유지하고, 두 영역을 상단 정렬했다.
- 기존 `/photos/about.webp`를 그대로 사용한다. 934×700 원본 비율을 유지하고, 사진 뒤에 #F1F1F1 오프셋 레이어를 적용했다. 반응형 `sizes`는 실제 표시 폭에 맞췄다.
- ‘상상마루는’은 24~28px로 설정하고 오른쪽에 #D9D9D9 수평선을 배치했다.
- ‘2012년부터, 익산의 학교와 함께.’는 데스크톱 42~48px·굵기 750·행간 1.25, 모바일 약 30~38px로 설정했다.
- 본문은 16~17px·굵기 400·행간 1.8, #333333을 사용한다. 기존 두 문단의 내용은 변경하지 않았다.
- 실적은 동일한 너비의 3열과 얇은 세로 구분선으로 구성했다. 숫자는 40~48px·굵기 750, 단위 14px, 설명 14~15px다. #111111과 #666666만 사용한다.
- 모바일에서는 연혁을 한 행 전체에 배치하고, 자격 23종·인증 및 지정 6개를 아래 두 열로 배치한다.

## 데이터와 동작

`historyHighlights`, `site.certifications`, `AboutIntroStats.tsx`는 수정하지 않았다. 2012년부터 연도와 대표 업적을 2초 간격으로 함께 전환하는 기존 기능을 유지한다. 2015년의 실제 내용은 ‘익산교육지원청 방과후마을학교 시즌1’이다. 화면별로 가장 긴 업적도 표시할 공간을 확보하여 전환 시 높이가 변하지 않도록 했다.

## 검증

- Chrome 390·768·1024·1280·1440·1784·1920px에서 가로 넘침, 텍스트 잘림, 사진 원본 비율, 제목 두 줄 표시를 확인했다.
- 1024px 이상은 2단 상단 정렬, 더 작은 화면은 세로 배치를 확인했다.
- 데스크톱 3개 실적의 동일한 너비와 세로 구분선 2개, 모바일의 두 열 배치와 구분선 1개를 확인했다.
- 기존 2012~2025 전체 대표 업적을 각 화면에서 측정해 실적 영역의 높이가 일정함을 확인했다.
- 실제 타이머가 2012→2013→2014→2015→2016 순으로 전환하고 각 연도와 기존 설명이 일치함을 확인했다.
- 브라우저 런타임 오류 없음.
- `npm run typecheck`, `npm run lint`, `npm run build` 모두 통과. 빌드는 68개 페이지를 생성했다.
- 검증 기록: Git 제외 경로 `.data/about-bw-validation.json`.
